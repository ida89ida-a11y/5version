About The Hackers' Game

This interactive game was created as a cyber security learning experience inspired by The Matrix universe.

The player must make choices related to phishing emails, online safety, and digital awareness.

Every decision affects the outcome of the story.

This game is intented to be for students on a vocational education like IBA, including exchange students, to learn about cyber security in a fun and engaging way.
